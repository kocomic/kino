# Kino 品牌规范

![Kino](../internal/server/web/assets/kino-logo.svg)

## 标志含义

标志以硬边字母 `K` 为主体，保留紫色错位底框、荧光绿识别面和白色竖向高光。它不是手柄、卡带或某台主机，因此不会把 Kino 限定为浏览器模拟器或单一设备前端。

## 使用规则

- 产品名始终写作 `Kino`；全大写 `KINO` 只用于字标。
- 不翻译、不另造简称。
- 界面内优先使用图形标志加 HTML 字标，保证多语言和缩放清晰。
- 不拉伸、旋转、圆角化或替换内部字母比例；小于 24 px 时使用 favicon 版本。
- 图标周围至少保留标志内侧白色竖条宽度两倍的净空。

## 色彩

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| Archive lime | `#B9F264` | 标志主面、关键状态、主操作 |
| Ink black | `#07080B` | 轮廓、背景、硬边分隔 |
| Offset violet | `#514770` | 错位阴影和漫画印刷层次 |
| Paper white | `#F4F6F0` | 小面积反差与深色背景字标 |
