# Quick start

Follow [deployment](DEPLOYMENT.md). Open the web interface, enter the owner token
in settings, then choose 导入 ROM. Select a server-visible path and platform,
review the scan, and commit selected candidates. Referenced ROMs stay in place.

The library supports title editing, edition grouping, primary editions, artifact
records and cover uploads. Advanced series, source configuration, hash packs
and maintenance are available through the [API](API.md). Pegasus and ES-DE
exports and complete-state backups are CLI operations.
